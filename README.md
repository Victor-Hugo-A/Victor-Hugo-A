# 🚀 Projetos em Destaque

## 🏛️ Sistema de Gestão de Recebimentos — MJSP

> **Projeto Full Stack institucional | Aplicação em produção | Código-fonte privado**

[![Acessar Aplicação](https://img.shields.io/badge/Acessar_Aplicação-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://mjsp-recebimentos-smtp.vercel.app)

Sistema web desenvolvido para auxiliar o **controle e acompanhamento de processos de recebimento**, centralizando informações e diferentes fluxos de usuários em uma única plataforma.

### Principais recursos

- 🔐 Autenticação e controle de acesso
- 🏢 Área específica para empresas
- 🇧🇷 Fluxos envolvendo as 27 Unidades Federativas
- 📝 Formulários estruturados em múltiplas etapas
- 📦 Registro e acompanhamento de recebimentos
- 📄 Geração de documentos em PDF
- ✉️ Envio de notificações via SMTP
- 📊 Painel administrativo
- 🔎 Consulta, filtros e histórico de registros
- 📤 Exportação de informações
- 📱 Interface responsiva

### Tecnologias

`Next.js` • `TypeScript` • `React` • `Prisma ORM` • `PostgreSQL` • `Neon` • `SMTP` • `Vercel`

> 🔒 O código-fonte é privado por se tratar de um projeto institucional. A aplicação é apresentada aqui como parte do meu portfólio técnico.
